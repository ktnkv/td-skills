# README

The text is in English. First the name of the tool and a short paragraph on why such a tool is worth having. Then exactly three sections, in this order. Do not add other sections.

```markdown
# Name

One short paragraph: what the tool does.

## How to use

1. Download `Name.*.tox` from the [latest release](https://github.com/<owner>/<repo>/releases/latest) and drop it into your project.
2. Next step.

## How it works

What the tool changes in the project, and what remains when the tool is off or absent.

## Limitations

- What it refuses or does not do.
```

The first step of `How to use` names the tox with a `*` in place of the version, so the README does not change at a release. Without a release page, say "from this repository" instead of the link.
