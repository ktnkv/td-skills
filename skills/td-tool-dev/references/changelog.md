# Changelog

Entries follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), in English. A version lists only the categories that have something in them, in this order:

- **Added** — new functionality
- **Changed** — changed existing functionality
- **Deprecated** — functionality marked as obsolete
- **Removed** — something was removed
- **Fixed** — a bug fix
- **Security** — security-related changes

The section of the new version is the body of its GitHub Release. Changes of other versions do not go into it.

```markdown
## 0.6.2

### Added

- One sentence about the new behavior.

### Fixed

- One sentence about the bug and the result.
```
